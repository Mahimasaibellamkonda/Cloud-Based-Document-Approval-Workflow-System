# Document Approval Workflow System

##  Project Description

Document Approval Workflow System is a cloud-based web application designed to manage the submission, review, approval, and rejection of business documents.

The system provides a centralized workflow where documents can be submitted by users and their approval status can be tracked through different stages.

---

##  Features

- Create new documents
- Edit existing documents
- Delete documents
- Submit documents for approval
- Mark documents as Under Review
- Approve documents
- Reject documents
- Search documents
- Filter by status
- Filter by priority
- Dashboard statistics
- Cloud-based data storage
- Responsive professional interface

---

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- Firebase
- Firebase Realtime Database

---

##  Cloud Technology

### Firebase Realtime Database

Firebase Realtime Database is used as the cloud database for storing document information.

All document records are stored in Firebase and retrieved dynamically by the web application.
